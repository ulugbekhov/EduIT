# EduIT — Interactive IT Platform Repository (Fixed Layout)

Fully flat repository layout without external script dependencies that lock visibility.

## 📁 Files Included
- `index.html` — Pure HTML5 structure with Bootstrap 5, CSS Animations, Multilingual support (UZ/RU/EN), Theme switcher, and Login Modal.
- `style.css` — Native CSS keyframe animations and styling.
- `script.js` — JavaScript ES6 logic for translation, theme toggling, and modal controls.
- `.gitignore` — Standard Git ignore configuration.
